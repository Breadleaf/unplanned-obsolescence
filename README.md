# Unplanned Obsolescence

My first combat robot! Plastic Antweight Division :)

`Weapon_Sketch_COM.FCMacro` to be added to macros in freecad.
To use it, you must have an active document, and active body.
The body must have the name "body_Weapon". Finally, run the script.
It will make a vertex where the COM is of the part.
I would advise to show the sketch of the weapon so you can compare to the
axis of rotation. I use the measure tool and click a point a set at the center
of my rotation axis and the vertex.

`OpenAll.bash` should be ran as `bash OpenAll.bash`. It will open all .FCStd
files in the `CAD/` directory. It only acts to make it faster to open all
relevant files.
